# آزمون سفارت · Azmoon Sefarat

Interactive practice for the Dutch **Spreekvaardigheid A1** exam taken at Dutch embassies (DUO, inburgering basisexamen).

- 40 tests × 30 multiple-choice questions (1200 questions), mixing Onderdeel A (questions) and Onderdeel B (aanvulzinnen)
- Persian (RTL) interface, Dutch questions
- Instant result: correct / wrong / unanswered, with the correct answer shown for every mistake
- Works offline and can be installed on Android and iPhone (PWA)

**Live:** https://danmo88.github.io/azmoon-sefarat/
